# Browser Game Live Ops

This package provides the core domain implementation for the Browser Game application. It owns the provider-neutral domain contracts, behavior, persistence, and authorization boundary for this capability.

## Installation

```bash
composer require liberusoftware/module-browser-game-live-ops
```

The package requires PHP 8.5 and Laravel 13. Enable it through the host application's module composition. It owns typed daily activities, events, seasons, schedules, announcements, grants, actor claims, lifecycle publication, versioning, and auditable rollback.
