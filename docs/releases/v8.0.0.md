# v8.0.0 — Dawnvale adventures and tactical combat

This major release replaces the generic player home with an adventure overview and adds a complete example world, guided account setup, and a persistent turn-based arena.

## Player experience

- Adventure dashboard with real XP progression, active quests, inventory, and clear next steps.
- Character creation through account setup with eight classes, distinct starting stats, and one-time starter kits.
- Revisit-able beginner guide with completion saved per account.
- Thirty-nine linked story quests with choices, prerequisites, hints, and one-time rewards.
- Ninety-seven example items covering weapons, armor, accessories, and crafting materials.

## Arena and NPCs

- Sixty seeded opponents across regional training, normal, elite, and boss encounters, spanning levels 1–84.
- Five tactical actions: quick strike, power strike, arcane burst, guard and focus, and second wind.
- Equipment and level bonuses, health/mana management, critical hits, adaptive NPC behavior, and persistent action logs.
- Opt-in player challenges requiring acceptance, alternating player turns, Elo-style ratings, and practice rematches.
- Participant authorization, atomic turn resolution, stale-turn rejection, reward cooldowns, challenge throttling, and timeout forfeits.
- Free rest between encounters, equipment preparation, paginated encounter discovery, and private battle reports.

## Administration

- Three-step game configuration wizard restricted to super administrators.
- One-click starter adventure and NPC installation.
- NPC management for stats, behavior, rewards, and availability; deactivation preserves battle history.
- Repeatable content installation that preserves existing edits, inventory, character progression, and battle records.

## Upgrade from v7

The release adds database columns and an NPC table. Run the migrations before serving the new panels. PHP 8.5 and the existing Laravel 13 / Filament 5 stack remain required.

```sh
composer install --no-interaction --prefer-dist
php artisan migrate --force
php artisan db:seed --class=NpcSeeder --force
npm ci
npm run build
php artisan optimize:clear
```

`NpcSeeder` installs missing starter quests and items as well as opponents. It does not create demonstration login accounts. Existing players can revisit account setup to choose a class and claim a starter kit without resetting their progress; existing class choices are preserved.

Enable PvP explicitly in **Admin → Overview → Game setup wizard**. Players must then opt in individually. Open `/app/battle-arena` to enter combat. Ordinary administrator-created quests do not receive the demonstration story-choice completion flow automatically.

See [the game experience guide](../game-experience.md) and [arena guide](../arena.md) for behavior, rewards, and configuration details.
